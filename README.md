# Shout for Mac

Shout is a menu-bar dictation app for macOS 14 and later. Hold **Fn**, speak, and your words appear in the text field you are using.

## Download

**[Download Shout for Mac](https://github.com/moritz-cvn/shout-releases/releases/latest/download/Shout.dmg)**

The app is signed by cavion GmbH and notarized by Apple.

## Install

1. Open **Shout.dmg** and drag **Shout** into Applications. Open Shout.
2. In **Settings → General**, enter your own OpenAI API key and click **Save key**. The key stays in your Mac's Keychain. You pay OpenAI directly for your usage.
3. Allow **Microphone**, **Input Monitoring** (for the Fn key) and **Accessibility** (to insert text) when macOS asks.
4. Click into a text field, hold **Fn** while you speak and let go when you are done.

Shout does not update itself yet. Download the latest version here to update.
